# bloom-filter-spellchecker
A Bloom filter based spellchecker in python.

Just download `spellchecker.py` and run it from the command line. In order to initialize the dictionary, you'll 
need to have `wordlist.txt` downloaded, as well. Alternatively, you can have the program download the word list 
directly from a URL. In order to do that, just do a CTRL+F search for "uncomment" in `spellchecker.py` and 
follow the directions in that comment block.
