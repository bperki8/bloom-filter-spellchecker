# bloom-filter-spellchecker
A Bloom filter based spellchecker in python.

In order to initialize the dictionary, you'll need to have `wordlist.txt` downloaded. Alternatively, you can 
have the program download the list directly from a URL. In order to do that, just do a CTRL+F search for
"uncomment" in `spellchecker.py` and follow the directions in that comment block.
